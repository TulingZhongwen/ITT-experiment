## 惯性-张力理论(ITT) 论文v1

ITT从三条不可再分的物理公设——**惯性、张力、自反性**——出发，提出意识涌现的最低物理条件：**闭环因果强度 Λ 超过噪声基准 Λ_noise**，并提供三个可由公开神经数据直接检验的预言。

### 三个核心预言

| 预言 | 内容 | 统计方法 |
|:---|:---|:---|
| **预言一（意识涌现的最低条件）** | 清醒时 Λ > Λ_noise；麻醉/深睡时 Λ ≈ Λ_noise | IAAFT置换检验，p < 0.01 |
| **预言二（意识度）** | 可访问自指距离 Θ(s) 随意识水平下降：清醒 > 困倦 > 麻醉 | Cohen's d > 0.8 |
| **预言三（方向规则）** | 系统自发运动方向与张力梯度存在系统性符号关系 | 块状Bootstrap，零假设50%，95%CI下限 > 0.50 |

**效应量分层（预言三）：**
- R > 0.75：强支持（ITT核心预测）
- R ∈ [0.60, 0.75]：弱支持（自反力存在，效应量低于预期）
- R ∈ [0.50, 0.60]：边缘（可能自反力微弱，或数据质量不足）
- R < 0.50：明确证伪

## 快速开始

### 1. 安装依赖

```bash
pip install numpy scipy scikit-learn matplotlib mne
```

### 2. 运行阶段一（仿真数据验证）

```bash
python ITT阶段一改进包.py
```

无需外部数据，应输出：
- Lorenz系统：Λ显著高于IAAFT噪声基准（p < 0.05）
- 白噪声：Λ与噪声基准无显著差异

### 3. 运行阶段二（公开EEG数据验证）

1. 从 [OpenNeuro](https://openneuro.org) 下载 **ds002718** 并解压
2. 修改 `ITT阶段二改进包.py` 中的 `data_path` 变量为你的本地路径
3. 运行：

```bash
python ITT阶段二改进包.py
```

输出：清醒与麻醉状态的Λ、Θ对比箱线图及统计检验结果

### 4. 运行阶段三（方向规则验证）

```bash
python ITT意识量化阶段三（方向规则）.py
```

输出：
- 正面对照（符合规则）：一致性比例及块状Bootstrap 95%CI
- 负面对照（纯噪声）：一致性比例
- 自动轨道选择（主轨道/简化轨道）
- 效应量分层判定
- 图表：`stage3_positive.png`、`stage3_negative.png`
