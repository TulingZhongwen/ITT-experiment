## 📖 惯性‑张力理论（ITT）

ITT 从三条不可再分的公设（惯性、张力、自反性）出发，提出意识涌现的物理条件：**闭环因果强度 Λ 超过噪声基准 Λ_noise**，并提供三个可实验检验的预言。

- **预言一（意识涌现条件）**：清醒时 Λ > Λ_noise，麻醉/深睡时 Λ ≈ Λ_noise。
- **预言二（意识度）**：可访问自指距离 Θ(s) 随意识水平下降（清醒 > 困倦 > 麻醉）。
- **预言三（自反力方向规则）**：系统自发运动方向与张力梯度之间的符号关系满足  
  `sgn(F_self·(-∇U)) = -sgn(Δ̅·∇U)`。

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install numpy scipy scikit-learn matplotlib mne

2. 运行阶段一（仿真验证）

```bash
python "ITT意识量化阶段一（仿真数据）.py"
```

或+改进包：

```bash
python "ITT阶段一改进包.py"
```

3. 运行阶段二（公开数据）

需要先从 OpenNeuro 下载 ds002718 数据集，修改脚本中的 data_path 后运行。

```bash
python "ITT意识量化阶段二（公开数据）.py"
```

或+改进包。

4. 运行阶段三（方向规则模拟测试）

```bash
python "ITT意识量化阶段三（方向规则）.py"
```

将输出正面对照（符合规则）和负面对照（纯噪声）的一致性比例及置换检验 p 值，并生成 stage3_permutation_test.png。

真实数据检验需自行实现 prepare_real_data 函数（见脚本注释）。
